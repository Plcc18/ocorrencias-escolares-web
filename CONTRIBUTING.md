# Contributing

Obrigado por contribuir! Por favor siga estes passos básicos:

1. Fork o repositório e crie uma branch com um nome descritivo.
2. Execute npm install e rode a aplicação localmente.
3. Formate o código com `npm run format` e rode os linters `npm run lint`.
4. Adicione testes quando possível (Vitest + React Testing Library).
5. Abra um Pull Request descrevendo as mudanças.

Para decisões arquiteturais maiores, abra um issue antes de implementar.
